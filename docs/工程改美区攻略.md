# 三星 QA75QN85BAJXXZ 工程区改美国：实测记录与操作攻略

本文只针对 **QA75QN85BAJXXZ，固件 T-PTMUABC-1651.7**。原来的工程菜单只有 `NONE`、`CHI_DTV`；本机通过 SDB 解除限制并写入 `AD_AU2`，冷启动后工程区仍为 `AD_AU2`。但 Smart Hub 国家代码当时仍是 `CN`，**美区商店尚未验证**。

**后续变化：这台电视目前已升级到 `T-PTMUABC-1720.7`，具体升级时间和触发原因未知。本文的内存地址与随包脚本只针对 1651.7，不能直接用于 1720.7；需要先针对新固件重新验证。**

实际更改步骤已在一台电视上手动验证。随文提供的备份工具、地区检查功能和“已在美区时不重复写入”分支已在该机测试；**自动设置脚本的写入分支尚未在第二台新电视上完整实测**。固件、主板或元件不同，都可能出现不同结果。

## 开始前

- 这是修改工厂参数，存在菜单异常、丢失设置、无法启动或需要维修的风险。照片和备份不能代替独立编程器恢复；建议具备维修及外接编程器条件后再进行。
- 在电视设置中确认型号和固件。建议先关闭 **设置 → 支持 → 软件更新 → 自动更新**，并拍照保存工程菜单的原始参数。[三星软件更新说明](https://www.samsung.com.cn/support/tv-audio-video/how-to-upgrade-tv-software/)
- 需要一台与电视处于同一局域网的 Mac、三星 Tizen Studio 的 `sdb`，以及 [samsung-tv-root](https://github.com/chris-ritsen/samsung-tv-root/releases) 的对应平台程序。本次使用 v0.0.12。开发者模式与连接方法可参考[三星开发文档](https://developer.samsung.com/smarttv/develop/faq/application-testing.html)。
- 本文不是修改固件，也不会自动重置 Smart Hub。不要尝试 `GetItem 194`；这里的 194 是内部 UID，直接当菜单编号查询曾使工厂服务重启。

## 1. 开启开发者模式并连接

在电视的 Apps 页面输入 `12345`，开启开发者模式，填入**电脑的局域网 IP**，再按电视提示重启。记录电视自己的局域网 IP；电脑 IP 和电视 IP 不是同一个地址。

在 Mac 终端中，先切换到本文及工具所在目录，并把下面三行替换为自己的实际路径和电视 IP：

```bash
TV="192.168.1.100"
SDB="/你的路径/tizen-studio/tools/sdb"
ROOT="/你的路径/samsung-tv-root"

"$SDB" connect "$TV"
"$SDB" devices
```

`devices` 列表中应出现电视。若连接失败，先确认电视和电脑在同一局域网、电视开发者模式填写的是电脑当前 IP。`samsung-tv-root` 使用的是临时 root；它是否可用仍取决于具体固件。

## 2. 备份 EEPROM

先在仓库 `tools` 目录编译备份读取程序（需要 .NET SDK 和 NuGet 目标框架依赖）：

```bash
dotnet build EepromRead.csproj -c Release -o build
cp build/EepromRead.dll build/EepromRead.runtimeconfig.json .
```

确认当前目录包含 `backup_eeprom.py`、生成的 `EepromRead.dll` 和 `EepromRead.runtimeconfig.json` 后执行：

```bash
python3 backup_eeprom.py "$TV" "$SDB" "$ROOT"
```

工具会先检查型号、固件和 EEPROM 驱动，再对 64 KiB EEPROM 只读两次并比较，保存为当前目录下的 `电视EEPROM备份-时间.bin`，文件权限为 0600。读取程序的源代码见 `EepromRead-source.cs`。**备份包含设备专属信息，不要公开；只覆盖该 EEPROM，不是整机固件备份，也尚未验证可以恢复。**备份失败就停止。

## 3. 确认工厂菜单项

执行下面的只读检查：

```bash
"$ROOT" --sdb "$SDB" -o json archive-root root "$TV" \
  --command 'gdbus call --system --timeout 5 --dest org.tizen.tv.factory-service --object-path /TIFacSerObj --method org.tizen.tv.factoryservice.GetItem 140202' \
  --command 'gdbus call --system --timeout 5 --dest org.tizen.tv.factory-service --object-path /TIFacSerObj --method org.tizen.tv.factoryservice.GetLocalSetListNo'
```

在一台尚未改区、与本次相同配置的电视上，预期第一项为 `Preventing Import`、值 `13`；第二项为 `((54, 43), (1,))`，其中当前存储索引 `43` 对应 `CHI_DTV`。工程菜单路径分别对应 **Control → Sub Option → Preventing Import** 和 **Option → Local Set**。如果名称、数值或固件不符，停止，先分析差异。

## 4. 解除地区过滤

确认备份完成、上述信息匹配后执行：

```bash
"$ROOT" --sdb "$SDB" -o json archive-root root "$TV" \
  --command 'gdbus call --system --timeout 8 --dest org.tizen.tv.factory-service --object-path /TIFacSerObj --method org.tizen.tv.factoryservice.SetParameter 761 0' \
  --command 'gdbus call --system --timeout 5 --dest org.tizen.tv.factory-service --object-path /TIFacSerObj --method org.tizen.tv.factoryservice.GetItem 140202'
```

第一条应报告 `((1,),)`，第二条的 `Preventing Import` 应显示 `0`。这是**持久修改工厂限制项**；任何结果不符都应停止，保留输出，不要继续猜测或刷固件。

## 5. 选择美国工程区

先运行检查，再执行设置：

```bash
python3 select_us.py "$TV" "$SDB" "$ROOT" --check
python3 select_us.py "$TV" "$SDB" "$ROOT" --apply
```

检查会核对型号、固件、限制项，并在电视运行时自动查找 `AD_AU2` 对应的菜单映射；检查本身不写入地区。设置后应看到 `Local Set` 为 `AD_AU2`。

**不要直接照抄 `SetParameter 194 1`。**这里的 `1` 是本次会话的菜单序号，不是始终固定的美国区值。不同查询顺序会改变映射，所以工具会实时核对。检查失败或返回非预期结果时停止。

如果电视工程菜单的 **Option → Local Set** 在解除过滤后能显示 `AD_AU2`，原厂界面也提供按名称选择的路径；这一界面点击路径在本机已通过程序代码核对，但未在第二台新电视上实际点击验证。

## 6. 重启并验证

电视开机时，长按遥控器电源键直到电视关闭并出现三星标志，然后重新连接 SDB。运行：

```bash
"$ROOT" --sdb "$SDB" -o json archive-root root "$TV" \
  --command 'gdbus call --system --timeout 5 --dest org.tizen.tv.factory-service --object-path /TIFacSerObj --method org.tizen.tv.factoryservice.GetItem 140202' \
  --command 'gdbus call --system --timeout 5 --dest org.tizen.tv.factory-service --object-path /TIFacSerObj --method org.tizen.tv.factoryservice.GetLocalSetListNo' \
  --command 'vconftool get db/comss/countrycode; vconftool get rtc/db/comss/gpmurl/store'
```

预期显示 `Preventing Import=0`，地区列表的当前存储索引为 `1`（例如 `((54, 1), (1,))`）。**只有确认限制项仍为 0 后**，才可额外查询菜单名称：

```bash
"$ROOT" --sdb "$SDB" -o json archive-root root "$TV" \
  --command 'gdbus call --system --timeout 5 --dest org.tizen.tv.factory-service --object-path /TIFacSerObj --method org.tizen.tv.factoryservice.GetItem 401'
```

此时应显示 `Local Set=AD_AU2`。若限制项不是 0，不要查询 401：本机代码显示这可能把被过滤的当前地区回退为 `NONE`。Smart Hub 的 `countrycode` 若仍是 `CN`，不能称应用商店已经是美区；商店域名从 `.cn` 变为 `.com` 也不能单独证明美区启用。

Smart Hub 重置可能清除账户和应用数据，且不保证这台国行电视会出现美国选项；应在确认后单独处理。**不要在 Local Set 仍为 `AD_AU2` 时直接把 Preventing Import 改回 13**：本机代码显示，被过滤的当前地区可能被回退为 `NONE`。恢复国区的方法尚未完整验证。
